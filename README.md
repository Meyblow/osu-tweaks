# osu!tweaks

[English](README.md) | [Русский](README.ru.md)

osu!cc plugin with useful gameplay tweaks and quality-of-life improvements for osu!lazer.

> [!NOTE]
> Looking for toolbar customization (drag & drop layout, floating island dock, geometry sliders, profile styling)?
> Those features have moved to [**Extended Toolbar**](https://github.com/Meyblow/extended-toolbar)!

### Features

- **Auto-skip (Intro, Breaks, Outro)**
  Automatically skip lead-in periods before the first note, mid-map breaks, and long waits after the last note, getting you straight to the action. Fully configurable (Breaks only, Intro only, Intro & breaks, All).

- **Dark Intro Flash on Startup**
  Replaces the bright white additive flash when launching the game with a smooth dark fade to protect your eyes.

### Install

1. Download the latest release from the [Releases](https://github.com/Meyblow/osu-tweaks/releases) tab.
2. Place `OsuTweaks.dll` into your osu!cc plugins folder:
   - **Windows**: `%APPDATA%\osu\osu-cc\plugins\osu-tweaks\`
   - **Linux / NixOS**: `~/.local/share/osu/osu-cc/plugins/osu-tweaks/`
3. Restart the game and configure settings under **Settings → osu!tweaks**.
