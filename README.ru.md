# osu!tweaks

[English](README.md) | [Русский](README.ru.md)

Плагин для osu!cc с полезными геймплейными твиками и улучшениями удобства игры для osu!lazer.

> [!NOTE]
> Ищете кастомизацию тулбара (Drag & Drop раскладка, плавающий остров / Dock, слайдеры геометрии, вид профиля)?
> Эти функции переехали в отдельный плагин — [**Extended Toolbar**](https://github.com/Meyblow/extended-toolbar)!

### Возможности

- **Автоскип интро и аутро**
  Автоматический пропуск времени до первой ноты и долгого ожидания после последней ноты на карте для быстрого перехода к игре и экрану результатов. Пропуск брейков полностью обрабатывается встроенным функционалом osu!cc.

- **Тёмная вспышка при запуске (Dark Intro Flash)**
  Убирает слепящую белую вспышку при старте игры, заменяя её мягким тёмным затуханием.

### Установка

1. Скачайте `OsuTweaks.dll` из вкладки [Releases](https://github.com/Meyblow/osu-tweaks/releases).
2. Поместите файл в папку плагинов osu!cc:
   - **Windows**: `%APPDATA%\osu\osu-cc\plugins\osu-tweaks\`
   - **Linux / NixOS**: `~/.local/share/osu/osu-cc/plugins/osu-tweaks/`
3. Перезапустите игру и настройте опции в **Настройки → osu!tweaks**.
