# osu!tweaks

[English](README.md) | [Русский](README.ru.md)

Компактный плагин для osu!cc с полезными геймплейными твиками и улучшениями удобства игры для osu!lazer.

> [!NOTE]
> Ищете модульную кастомизацию тулбара (Drag & Drop раскладка, плавающий остров / Dock, слайдеры геометрии, вид профиля)?
> Эти функции переехали в отдельный плагин — [**Extended Toolbar**](https://github.com/Meyblow/extended-toolbar)!

## ✨ Возможности

### ⏩ Умный автоскип на State Machine
Автоматически пропускает неигровые паузы на картах, чтобы вы сразу переходили к игре:
- **Пропуск интро**: Пропускает время до первой ноты, плавно начиная воспроизведение за 2 секунды до объекта.
- **Пропуск брейков (пауз)**: Определяет секции отдыха на карте и быстро перематывает их до завершения паузы (с запасом 2 секунды до следующей ноты).
- **Пропуск аутро**: Быстро перематывает долгое затухание после последней ноты сразу к экрану результатов.
- **Выбор режимов работы**:
  - `Отключено`: Без автоскипа.
  - `Только брейки (паузы)`: Пропуск только пауз в середине карты.
  - `Только интро`: Пропуск только начала карты.
  - `Интро и брейки`: Пропуск начала карты и пауз.
  - `Всё (Интро, брейки и аутро)`: Полная автоматизация пропуска.

### 🌙 Тёмная вспышка при запуске (Dark Intro Flash)
Устраняет ослепляющую белую аддитивную вспышку (`GameWideFlash`) при старте игры, заменяя её мягким тёмным затуханием.

## 📦 Установка

1. Перейдите во вкладку [Releases](https://github.com/Meyblow/osu-tweaks/releases).
2. Скачайте `OsuTweaks.dll` (или `plugin-osu-tweaks-1.4.0.zip`).
3. Поместите файл в папку плагинов osu!cc:
   - **Windows**: `%APPDATA%\osu\osu-cc\plugins\osu-tweaks\`
   - **Linux / NixOS**: `~/.local/share/osu/osu-cc/plugins/osu-tweaks/`
4. Запустите игру и настройте нужные опции в **Настройки → osu!tweaks**.
